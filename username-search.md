Username & Alias Search

A collection of OSINT resources for checking usernames and aliases across publicly accessible websites and services.

These tools can help researchers discover publicly visible profiles associated with a username. Search results should be treated as leads, not proof of identity.

Username Search Tools

Sherlock

* Repository: https://github.com/sherlock-project/sherlock
* Purpose: Searches many websites for accounts associated with a supplied username.
* Type: Open-source command-line tool.
* Best for: Checking whether a username may exist across multiple platforms.

Maigret

* Repository: https://github.com/soxoj/maigret
* Purpose: Searches websites for accounts associated with a username and can generate reports.
* Type: Open-source command-line tool.
* Best for: Broader username research and documenting results.

WhatsMyName

* Repository: https://github.com/WebBreacher/WhatsMyName
* Purpose: Maintains a collection of website checks for username enumeration.
* Type: Open-source project and data resource.
* Best for: Identifying websites where a username may have a public profile.

Search Engine Techniques

Try searching for an exact username:

"username123"

Search for a username on a specific website:

site:reddit.com "username123"

Search for a username alongside a public profile reference:

"username123" profile

Replace username123 with the username being researched.

Important Considerations

* The same username may be used by unrelated people.
* A search result does not guarantee that an account is active or belongs to a particular person.
* False positives can occur when websites block automated requests or return misleading results.
* Respect website terms, privacy, and applicable laws.
* Do not use these resources to harass, stalk, or expose private information.
