OSINT Search Resources

A curated collection of Open-Source Intelligence (OSINT) resources, search engines, investigation tools, and advanced search techniques for discovering and analyzing publicly available information online.

The goal of this repository is to provide a centralized reference for OSINT research, making it easier to find useful tools and resources without having to search for them individually.

Search Engines & Advanced Search

Resources for finding publicly indexed information using search engines, search operators, and targeted queries.

Useful techniques include:

* Exact-phrase searches
* Searching within specific websites using site:
* Searching page titles using intitle:
* Searching URLs using inurl:
* Combining multiple search terms to narrow results

Username & Alias Search

Tools and resources for checking whether a username or alias appears on multiple publicly accessible websites.

Examples:

* Sherlock — checks websites for accounts associated with a username.
* Maigret — username-search tool that can generate reports.
* WhatsMyName — project for username enumeration across websites.

A matching username does not necessarily mean that multiple accounts belong to the same individual.

Real Name Search

Resources for researching names through publicly accessible sources, professional directories, published records, and search engines.

Results should be independently verified because different people can share the same name.

Social Media Research

Resources for locating and reviewing publicly available social media profiles and posts.

Platforms of interest may include:

* Reddit
* Instagram
* Facebook
* TikTok
* LinkedIn
* YouTube
* X

Availability and search functionality vary by platform.

Phone Number Lookup

Resources for researching phone numbers, including:

* International dialing codes and number formats
* Number validation and formatting
* Carrier information where available
* Public spam-call and scam-report databases
* Publicly indexed references to a number

Lookup results may be incomplete or outdated. Carrier information does not necessarily identify the current owner of a number.

Email & Domain Research

Resources for examining publicly available domain information, DNS records, website infrastructure, and email-related technical information.

This category may include domain registration lookups, DNS tools, certificate transparency resources, and email security checks.

Image & Reverse Image Search

Tools for locating visually similar images and publicly available copies of an image.

Potential uses include checking image origins, finding duplicate publications, and verifying the context in which an image appears.

OSINT Guides & Learning Resources

Educational materials covering search techniques, source verification, digital investigation methodology, and responsible open-source research.

Responsible Use

This repository is intended for educational purposes, cybersecurity research, fraud prevention, and lawful investigations using publicly available information.

* Respect privacy, applicable laws, and website terms of service.
* Do not use these resources to harass, stalk, dox, or threaten individuals.
* Do not assume that matching usernames, names, images, or phone numbers establish a person’s identity.
* Verify important findings through multiple independent sources.
* Avoid publishing sensitive personal information or unverified allegations.

Contributing

Suggestions for additional resources, corrections, and improvements are welcome.

When suggesting a resource, include its name, official URL, purpose, relevant category, and any important limitations.

Please prioritize reputable sources, maintained projects, and resources with clear documentation.
